# 🌱e-plantShopping

This React website offers such features as a landing page, products overview with images and descriptions as well as a cart that shows total

## Highlights
 - Landing page with a button
 - Cart created with React Redux
 - Components for dynamic rendering of products

## Author 
This project is made by me for the IBM React Final Project task, but I will also use it for reference in the future and plan on creating a more complex ecom website.

## Installation
```bash
git clone https://github.com/bytecuriosity/e-plantShopping
npm install
npm run preview
```
